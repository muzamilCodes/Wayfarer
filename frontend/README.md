# Wayfarer frontend (Next.js 14)

    cd frontend && cp .env.example .env.local
    npm install && npm run dev      # http://localhost:3000  (backend must run on :5000)

Built: 3D hero (lazy, capability-tiered, static fallback), destinations, tours with filters + pagination,
tour detail (itinerary, sticky booking estimate, JSON-LD), login/register with email OTP, sitemap, robots.
Linked but not built yet: /plan /hotels /cabs /activities /blog /wishlist /contact and policy pages.
